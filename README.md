# hello-world

Interface web d'un **tableau de bord interactif pour une Direction des Systèmes d'Information (DSI)** en HTML/CSS/JS vanilla.

## Lancer le projet

```bash
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Fonctionnalités

- Navigation entre 4 vues DSI (`Vue DSI`, `Infrastructure`, `Cybersécurité`, `Support utilisateurs`)
- KPI métiers IT dynamiques selon la section
- Graphique en barres interactif avec métriques contextuelles
- Mode sombre
- Design responsive

## Données

Les valeurs affichées sont des **données simulées** pour démonstration.

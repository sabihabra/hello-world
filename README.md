# hello-world

Interface web d'un **tableau de bord interactif** (HTML/CSS/JS vanilla).

## Lancer le projet

```bash
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Fonctionnalités

- Navigation entre 3 sections (`Vue globale`, `Ventes`, `Trafic`)
- KPI dynamiques
- Graphique en barres interactif (métrique sélectionnable)
- Mode sombre
- Design responsive
